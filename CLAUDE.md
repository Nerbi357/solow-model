# CLAUDE.md

Интерактивный учебный инструмент по модели Солоу для семинара
по макроэкономике. Публикуется на GitHub Pages, студенты открывают
его в браузере со своих ноутбуков и телефонов.

## Структура

```
index.html   — весь инструмент: разметка, стили и логика в одном файле
.nojekyll    — отключает обработку Jekyll на GitHub Pages
README.md    — описание для людей
LICENSE      — MIT
```

Файлов с кодом больше нет и появляться не должно.

## Конвенции

Ниже — правила, которым обязана следовать любая будущая правка.
Это не пожелания: на них держится и работоспособность страницы
в аудитории, и её педагогический смысл.

### 1. Один файл, ноль зависимостей

Весь код живёт в `index.html`: разметка, `<style>` и `<script>`
внутри одного документа. Запрещены:

* внешние библиотеки и фреймворки;
* любые CDN-ссылки;
* подгружаемые шрифты (`@font-face` с сетевым URL, Google Fonts и т. п.);
* сборка, бандлеры, шаги транспиляции;
* сетевые запросы во время работы страницы.

Файл должен полностью работать офлайн: открыт двойным щелчком
из папки, с флешки, из аудитории без вайфая. Шрифты задаются
только системным стеком (`PT Serif`, `Georgia`, `Times New Roman`, `serif`).

### 2. Визуальный стиль — бумага без клетки

* тёплая бумага в качестве фона, никакой клетчатой подложки под графиком:
  её убрали намеренно, возвращать не надо;
* засечный шрифт во всём интерфейсе, включая подписи на canvas;
* вся палитра задана CSS-переменными в `:root` — новые цвета добавляются
  туда же, хардкод цветовых литералов в коде отрисовки не допускается
  (единственное исключение — полупрозрачная подложка под подписями);
* десятичный разделитель — запятая (`num`, `pct`); ввод понимает и запятую,
  и точку (`parseRu`).

### 3. Смысл цвета — он говорит только о шоках

Исходное состояние рисуется **чёрным, обычной толщиной, сплошной линией** —
все три кривые одинаково. Какая это кривая, видно по подписи у правого края,
а не по штриху или толщине.

Цвет появляется только там, где шок что-то сдвинул:

| Переменная        | Что означает                                     |
|-------------------|--------------------------------------------------|
| `--ink`           | исходное состояние, все три кривые               |
| `--sh1` … `--sh6` | шоки 1, 2, 3…, жирной линией                     |
| `--result`        | совместная кривая, когда два шока тянут одну     |
| `--ochre`         | golden rule                                      |
| `--graphite`      | второстепенный текст                             |
| `--up`/`--down`   | стрелки роста и падения в таблице                |

Правило, которое ломать нельзя: **шок перекрашивает только ту линию, на
которую он непосредственно влияет.** Таблица `AFFECTS` — источник истины:

```
s            → s·f(k)
δ, n, g      → (δ+n+g)k
α, σ         → f(k) и s·f(k)
K ×, L ×     → ничего: они двигают точку, а не кривые
```

Шок, который ещё стоит на исходном значении, не красит вообще ничего
(предикат `bites`): линия остаётся чёрной, пока шок не скажет что-то новое.
Он же не попадает ни в таблицу, ни в легенду, ни в список точек.

Цвет шока берётся только через `colHex(ci)` (canvas) и `colVar(ci)`
(разметка), по индексу `ci`, который выдаётся при создании и живёт с шоком
до удаления. Руками цвет не назначается — иначе номер и цвет разъедутся.

### 4. Язык

Весь интерфейс — на русском. Исключение ровно одно: подпись золотого
правила на диаграмме называется `golden rule`. Идентификаторы в коде
и комментарии — на английском.

### 5. Ключевая педагогическая логика — не ломать

Это главное правило файла.

* **Ползунки параметров (`s`, `δ`, `n`, `g`, `α`, `σ`) двигают кривые,
  но НЕ двигают точку `k`.** Запас капитала предопределён прошлым: он не
  может прыгнуть оттого, что экономика поменяла норму сбережений. Кривые
  уезжают, точка остаётся, и между инвестициями и выбытием открывается
  разрыв — он и есть разница между коротким и длинным периодом.

* **Множители шока (`K ×`, `L ×`) наоборот двигают точку, не трогая
  кривые.** Разовое изменение запаса капитала или числа работников меняет
  `k = K/(L·A)`, но не меняет ни технологию, ни поведение.

Любая правка, после которой ползунок параметра дёргает точку `k`, а шок
сдвигает кривые, считается поломкой, даже если код стал короче. На это
есть тесты, и они должны оставаться.

Из того же принципа `k` нигде не хранится отдельной переменной: он всегда
выводится из `base` и списка шоков.

### 6. Графика

* всё рисуется на `<canvas>` вручную, без графических библиотек;
* обязателен учёт `devicePixelRatio` — размер буфера считается как
  CSS-ширина × dpr, трансформация ставится через
  `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` (см. `fitCanvas`);
* диаграмма разделена на чистый `renderMain(ctx, w, h, capture)`, который
  рисует в любой контекст заданного размера в CSS-пикселях, и обёртку
  `drawMain()`. Экспорт PNG переиспользует ту же функцию с масштабом ×2 —
  дублировать отрисовку нельзя. `capture` включает запись экранных
  координат точек в `HITS` и рамки в `FRAME`: при экспорте он выключен;
* `drawMain()` вызывается **до** `renderLegend()`, потому что легенда
  читает `FRAME`, чтобы не показывать то, что не нарисовалось;
* подписи кривых у правого края разводятся `spread()`, подписи точек —
  выносятся от самой точки.

### 7. Доступность и мобильные

* видимый фокус с клавиатуры у всех интерактивных элементов — контур
  не снимать;
* точки на диаграмме обязаны быть доступны без мыши: стрелки переходят
  между ними, Enter отмечает, Escape снимает все отметки;
* страница обязана работать на телефоне: панель уходит вниз под график
  (медиазапрос `max-width: 1100px`), широкая таблица прокручивается внутри
  своей рамки, а не тянет всю страницу;
* `prefers-reduced-motion: reduce` уважается.

## Состояние

```js
let base   = {s, d, n, g, a, sg};              // исходное состояние
let shocks = [{key, value, on, ci}];           // не больше одного на параметр
```

**Все шоки происходят одновременно.** Каждый отсчитывается от `base`,
а не от предыдущего шока: `paramsOf(sh)` — это `base` с одним изменённым
параметром, `finalP()` — `base` со всеми сразу. Цепочек больше нет
и заводить их не надо.

**Один шок — один параметр.** Занятый параметр исчезает из списка
доступных, а `readHash` отбрасывает дубликаты. Нужно больше изменений —
больше шоков.

## Точки и координаты

`pointList()` собирает пересечения, которые имеет смысл читать: для каждого
состояния (исходного, каждого шока по отдельности, совместного и состояния
сразу после шоков) — точка, где `s·f(k)` встречает линию выбытия, и уровень
выпуска над ней. Совпадающие точки схлопываются, поэтому один шок по `δ`
даёт ровно четыре точки, а не пять: «новая s при старой δ» не существует.

Щелчок по точке разворачивает её координаты, второй — убирает. График
безразмерный, поэтому координаты **относительные**: исходный стационар
равен `(1; 1)`, остальное — в долях от него (`refs`, `relOf`). В таблице
под графиком каждая следующая отмеченная точка сравнивается с первой —
в разах и процентах.

## Таблица «Что происходит с переменными»

Строка на каждый шок — его изолированный эффект против исходного состояния,
плюс строка «итого» со всеми шоками сразу (она появляется, когда шоков
больше одного). Ответов ровно четыре, как на семинарском листке:
увеличилось, уменьшилось, не изменилось, нельзя определить. Сравнение
численное, допуск `2e-4`. «Нельзя определить» — там, где длинного периода
действительно нет.

## Задачи с семинара

Массив `PROBLEMS` — пул готовых разборов. Формат описан комментарием прямо
над массивом: заголовок, подсказка, постановка, объяснение, `base`
и список одновременных `shocks`, в каждом ровно один параметр. Добавление
разбора не должно требовать правок где-либо ещё.

## Модель

Производственная функция — CES:

```
f(k) = [α·k^ρ + (1−α)]^(1/ρ),   ρ = (σ−1)/σ
```

Накопление: `Δk = s·f(k) − (δ+n+g)·k`.

`σ` — **эластичность замещения**, а не сумма степеней при `K` и `L`:
`σ = d ln(K/L) / d ln(MPL/MPK)`. Сумма степеней у Кобба — Дугласа равна
единице — это постоянная отдача от масштаба, другое свойство, и у CES оно
выполняется при любой `σ`. У Кобба — Дугласа `σ = 1` при любой `α`.

При `σ = 1` показатель обращается в бесконечность, поэтому этот случай
обрабатывается **отдельной веткой** `f(k) = k^α`. Порог — `|σ − 1| < 1e-3`
(`SG_TOL`, предикат `sgOne`). Убирать ветку нельзя: без неё всё
обращается в `NaN`.

### Стационар существует не всегда

Средний продукт `f(k)/k` монотонно убывает от `A₀` до `A∞`:

```
σ > 1:  A₀ = ∞,                  A∞ = α^(σ/(σ−1)) > 0
σ < 1:  A₀ = α^(σ/(σ−1)) < ∞,    A∞ = 0
σ = 1:  A₀ = ∞,                  A∞ = 0
```

Каждый уровень `f(k)/k = q` достигается не более одного раза, поэтому и
`k*`, и золотое правило берутся из одной закрытой формы:

```
k(q)   = [(1−α)/(q^ρ − α)]^(1/ρ)     — существует при q^ρ > α
k*     = k(q) при q = (δ+n+g)/s
k_gold = k(q) при q = ((δ+n+g)/α)^σ
```

Это `kAtAPK(q, p)`; при нарушении `q^ρ > α` она возвращает `NaN`, и все
ветки отрисовки обязаны проверять это через `isFinite`. Что происходит
в таком состоянии, говорит `regime()`: `explosive` при `σ > 1` (капитал
растёт без предела) и `collapse` при `σ < 1` (вырождается к нулю). На
диаграмме вместо `k*` появляется надпись, в таблице — «нельзя определить».

### Остальные величины

```
s_gold = α^σ·(δ+n+g)^(1−σ)          — при σ = 1 вырождается в s = α
s_crit = (δ+n+g)/α^(σ/(σ−1))        — граница существования стационара
f′(k)  = α·(f(k)/k)^(1/σ)
θ(k)   = α·(k/f(k))^ρ                — доля капитала; при CES НЕ равна α
λ      = (1 − θ*)·(δ+n+g)            — при σ = 1 это (1−α)(δ+n+g)
```

## Диапазоны параметров

`META` — единственное место, где они заданы: границы, шаг, число знаков
и человеческое название. У `s`, `δ` и `α` нижняя граница `0,01`, потому
что ноль там вырожден. У `n` и `g` она **нулевая** и такой должна остаться:
«без роста населения» — стандартная точка отсчёта, на ней стоят все
семинарские задачи. Верхняя граница у всех пяти — `0,99`.

Каждый параметр правится и ползунком, и числом в ячейке. Ячейка принимает
запятую и точку, клампит по границам `META` и подсвечивается, если введено
нечитаемое; значение при этом не применяется.

## Состояние в URL

Всё состояние — `base`, список шоков, открытая задача и отмеченные точки —
кодируется в хеше. При загрузке значения клампятся по `META`, дубликаты
шоков по одному параметру отбрасываются: правленая руками ссылка не должна
загонять модель туда, откуда интерфейс не выберется.

## Отрисовка и перерисовка

* `refreshAll()` — пересобирает разметку панели (ползунки, карточки шоков,
  список задач) и потом зовёт `refreshLive()`. Только при изменении
  структуры: добавили шок, убрали, загрузили задачу, прочитали хеш.
* `refreshLive()` — обновляет значения **на месте** (`syncValues`) и
  перерисовывает всё производное. Только это можно звать из обработчика
  `input`: пересборка разметки во время перетаскивания вырывает ползунок
  из-под курсора.

## Проверка перед коммитом

Автотестов в репозитории нет — проверяется руками:

```
python3 -m http.server 8000
```

Открыть `http://localhost:8000/`, убедиться, что в консоли пусто,
и пройти чек-лист:

1. ползунки и ячейки двигают кривые, точка `k` стоит на месте;
2. `K ×` и `L ×` двигают точку, кривые стоят;
3. свежедобавленный шок не красит ни одной линии;
4. шок по `s` красит только `s·f(k)`, по `δ` — только линию выбытия,
   по `σ` — обе кривые выпуска;
5. один параметр нельзя занять дважды;
6. шоки одновременны: второй шок отсчитывается от исходного состояния,
   а не от первого;
7. щелчок по точке разворачивает координаты, второй убирает, вторая точка
   сравнивается с первой;
8. ячейка принимает «0,25», клампит «7» и подсвечивает «abc»;
9. таблица совпадает с числами — проверьте хотя бы задачу 1.i (короткий
   период всё вниз, длинный — всё «не изменилось»);
10. ссылка восстанавливает состояние целиком;
11. «Сохранить PNG» отдаёт картинку с белым фоном и вдвое большим
    разрешением;
12. страница не разъезжается на узком экране;
13. Tab проходит по всем контролам, стрелки ходят по точкам.

Коммит — после каждой удачной правки, мелкими шагами: так любую поломку
можно откатить одним `git revert`, а GitHub Pages обновится сам.
