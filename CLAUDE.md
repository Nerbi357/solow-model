# CLAUDE.md

Интерактивный учебный инструмент по модели Солоу для семинара
по макроэкономике. Публикуется на GitHub Pages, студенты открывают
его в браузере со своих ноутбуков и телефонов.

## Структура

```
index.html   — весь инструмент: разметка, стили и логика в одном файле
.nojekyll    — отключает обработку Jekyll на GitHub Pages
README.md    — описание для людей
LICENSE      — MIT
```

Файлов с кодом больше нет и появляться не должно.

## Конвенции

Ниже — правила, которым обязана следовать любая будущая правка.
Это не пожелания: на них держится и работоспособность страницы
в аудитории, и её педагогический смысл.

### 1. Один файл, ноль зависимостей

Весь код живёт в `index.html`: разметка, `<style>` и `<script>`
внутри одного документа. Запрещены:

* внешние библиотеки и фреймворки;
* любые CDN-ссылки;
* подгружаемые шрифты (`@font-face` с сетевым URL, Google Fonts и т. п.);
* сборка, бандлеры, шаги транспиляции;
* сетевые запросы во время работы страницы.

Файл должен полностью работать офлайн: открыт двойным щелчком
из папки, с флешки, из аудитории без вайфая. Шрифты задаются
только системным стеком (`PT Serif`, `Georgia`, `Times New Roman`, `serif`).

### 2. Визуальный стиль — миллиметровка

* тёплая бумага в качестве фона, бледно-бирюзовая сетка миллиметровки
  под графиками;
* засечный шрифт во всём интерфейсе, включая подписи на canvas;
* вся палитра задана CSS-переменными в `:root` — новые цвета
  добавляются туда же, хардкод цветовых литералов в коде отрисовки
  не допускается (единственное исключение — полупрозрачная подложка
  под текстовыми подписями);
* десятичный разделитель — запятая, как принято в русской типографике
  (за это отвечают хелперы `num` и `pct`).

### 3. Смысл цветов

Цвет здесь несёт содержание, а не украшает. Значения закреплены:

| Переменная    | Цвет            | Что означает                          |
|---------------|-----------------|---------------------------------------|
| `--ink`       | чернильный      | текущее состояние: кривые и стационар |
| `--ink-soft`  | приглушённый    | линия выбытия `(δ+n+g)k`              |
| `--pencil`    | серый пунктир   | «как было» — сохранённая конфигурация |
| `--red`       | красный         | текущая точка `k` и всё, что при ней  |
| `--ochre`     | охра            | золотое правило                       |
| `--graphite`  | графит          | второстепенный текст и пояснения      |

Перекрашивать элементы между этими ролями нельзя: студент читает
диаграмму по цвету.

### 4. Язык

Весь интерфейс — на русском. Подписи, кнопки, показатели, тексты
на canvas, сообщения об особых случаях. Идентификаторы в коде
и комментарии — на английском.

### 5. Ключевая педагогическая логика — не ломать

Это главное правило файла.

* **Ползунки параметров (`s`, `δ`, `n`, `g`, `α`, `σ`) двигают кривые,
  но НЕ двигают точку `k`.** Запас капитала предопределён прошлым:
  он не может прыгнуть оттого, что экономика поменяла норму
  сбережений. Кривые уезжают, точка остаётся, и между инвестициями
  и выбытием открывается разрыв — именно он и есть переходная динамика.

* **Множители шока (`K ×`, `L ×`) наоборот двигают точку, не трогая
  кривые.** Разовое изменение запаса капитала или числа работников
  меняет `k = K/(L·A)`, но не меняет ни технологию, ни поведение:
  `f(k)`, `s·f(k)` и `(δ+n+g)k` остаются на месте.

Это различие — суть всего инструмента. Любая правка, после которой
ползунок параметра дёргает точку `k`, а шок сдвигает кривые, считается
поломкой, даже если код при этом стал короче.

Из того же принципа: `k` меняется только через шок, кнопки перехода
(`Запустить`, `Сразу в k*`), выбор сценария и чтение состояния из URL.

### 6. Графика

* всё рисуется на `<canvas>` вручную, без графических библиотек;
* обязателен учёт `devicePixelRatio` — размер буфера `canvas.width`
  считается как CSS-ширина × dpr, трансформация ставится через
  `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` (см. `fitCanvas`);
  иначе на ретине линии мылятся;
* главная диаграмма разделена на чистый `renderMain(ctx, w, h)`, который
  рисует в любой контекст заданного размера в CSS-пикселях, и обёртку
  `drawMain()`, привязанную к элементу. Экспорт PNG переиспользует ту же
  чистую функцию с масштабом ×2 — дублировать отрисовку нельзя;
* перерисовка — на `resize` и на любое изменение состояния.

### 7. Доступность и мобильные

* видимый фокус с клавиатуры: у всех интерактивных элементов есть
  `:focus-visible` с заметной обводкой — контур не снимать;
* страница обязана работать на телефоне: колонка полей уходит вниз
  под графики на узких экранах (медиазапрос `max-width: 980px`),
  графики остаются читаемыми, подписи не наезжают друг на друга;
* `prefers-reduced-motion: reduce` уважается: анимация перехода
  не проигрывается, состояние сразу переставляется в конечное.

## Модель

Производственная функция — CES:

```
f(k) = [α·k^ρ + (1−α)]^(1/ρ),   ρ = (σ−1)/σ
```

Накопление: `Δk = s·f(k) − (δ+n+g)·k`.

При `σ = 1` показатель обращается в бесконечность, поэтому этот случай
обрабатывается **отдельной веткой** `f(k) = k^α`. Порог — `|σ − 1| < 1e-3`
(константа `SG_TOL`, предикат `sgOne`). Убирать эту ветку нельзя: без неё
`1/ρ` уходит в бесконечность и всё обращается в `NaN`.

### Стационар существует не всегда

Средний продукт `f(k)/k` монотонно убывает от `A₀` до `A∞`:

```
σ > 1:  A₀ = ∞,                  A∞ = α^(σ/(σ−1)) > 0
σ < 1:  A₀ = α^(σ/(σ−1)) < ∞,    A∞ = 0
σ = 1:  A₀ = ∞,                  A∞ = 0
```

Поэтому каждый уровень `f(k)/k = q` достигается не более одного раза,
и k для него берётся из одной закрытой формы:

```
k(q)   = [(1−α)/(q^ρ − α)]^(1/ρ)     — существует при q^ρ > α
k*     = k(q) при q = (δ+n+g)/s
k_gold = k(q) при q = ((δ+n+g)/α)^σ
```

Это `kAtAPK(q, p)`; при нарушении `q^ρ > α` она возвращает `NaN`, и все
ветки отрисовки обязаны это проверять через `isFinite`. Что происходит
в таком состоянии, говорит `regime()`:

* `explosive` (`σ > 1`) — `s·f(k)` навсегда выше линии выбытия, капитал
  растёт без предела. На диаграмме вместо `k*` появляется надпись
  **«стационара нет: капитал растёт бесконечно»**;
* `collapse` (`σ < 1`) — зеркальный случай: инвестиции нигде не покрывают
  выбытие, капитал вырождается к нулю, надпись об этом же.

В обоих состояниях кнопка «Сразу в k*» отключается, `k*` в показателях
печатается как «—», а горизонт симуляции считается не от `λ`, а от
текущего темпа роста.

### Остальные величины

```
s_gold = α^σ·(δ+n+g)^(1−σ)          — при σ = 1 вырождается в s = α
s_crit = (δ+n+g)/α^(σ/(σ−1))        — граница существования стационара:
                                       при σ > 1 сверху, при σ < 1 снизу
f′(k)  = α·(f(k)/k)^(1/σ)
θ(k)   = α·(k/f(k))^ρ                — доля капитала в доходе; при CES
                                       она НЕ равна α
λ      = (1 − θ*)·(δ+n+g)            — при σ = 1 это (1−α)(δ+n+g)
```

## Состояние в URL

Всё состояние — параметры, `k`, сохранённое «как было» и открытая
вкладка — кодируется в хеше URL, чтобы ссылкой на конкретную конфигурацию
можно было поделиться со студентами. При загрузке хеш читается, значения
клампятся по `min`/`max` соответствующих ползунков: правленая руками
ссылка не должна загонять модель туда, откуда интерфейс не выберется.

Добавляя новый параметр, заведите его в `HASH_KEYS` — сериализация,
разбор и клампинг идут по одному списку. Иначе старые ссылки начнут
молча терять настройку.

## Проверка перед коммитом

Автотестов нет — проверяется руками:

```
python3 -m http.server 8000
```

Открыть `http://localhost:8000/`, убедиться, что в консоли пусто,
и пройти чек-лист:

1. ползунки двигают кривые, точка `k` стоит на месте;
2. «Применить шок» двигает точку, кривые стоят;
3. «Запустить» проигрывает переход, «Сразу в k*» ставит точку в стационар;
4. «Запомнить как „было“» рисует серый пунктир прежней конфигурации;
5. при `σ = 1` картинка ровно та же, что была у Кобба — Дугласа;
6. `σ = 2`, `α = 0,5`, `s = 0,60` показывает надпись об отсутствии
   стационара, и «Сразу в k*» при этом недоступна;
7. ссылка из «Скопировать ссылку», открытая заново, восстанавливает
   состояние целиком;
8. «Сохранить PNG» отдаёт картинку с белым фоном и вдвое большим
   разрешением;
9. все сценарии отрабатывают без ошибок в консоли;
10. страница не разъезжается на узком экране;
11. Tab проходит по всем контролам с видимым фокусом.

Коммит — после каждой удачной правки, мелкими шагами: так любую
поломку можно откатить одним `git revert`, а GitHub Pages обновится сам.
