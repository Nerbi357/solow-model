Что не так: когда свободны сразу два (и больше) из {s, δ, n, g}, сторону k=1 решает сравнение s с (δ+n+g) — то есть все свободные из них сразу, — но подпись называет только первый по порядку (s, потом δ, n, g). Собственный комментарий разработчика над этим кодом (index.html:1390-1391) обещает другое: «в пояснении называются только те из них, которые условие оставило свободными» — во множественном числе, — то есть баг противоречит и намерению автора, не только ожиданию студента.
