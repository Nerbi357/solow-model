# Модель Солоу — интерактивная диаграмма

Учебный инструмент для семинара по макроэкономике. Одна страница,
на которой можно руками подвигать параметры модели Солоу и увидеть,
куда уезжает стационарное состояние — и, главное, что запас капитала
уезжает туда не сразу.

**Живая страница: https://nerbi357.github.io/solow-model/**

Весь инструмент — один файл `index.html` без внешних зависимостей.
Его можно скачать и открыть двойным щелчком: интернет нужен только
чтобы получить файл, дальше он работает офлайн.

## Что внутри

**Диаграмма накопления.** Выпуск `f(k)`, инвестиции `s·f(k)`, линия
выбытия `(δ+n+g)k`; стационар `k*`, золотое правило, текущая точка `k`
и стрелка разрыва между инвестициями и выбытием — та самая, что
показывает, растёт капитал или падает.

**Динамика во времени.** Как `k`, `y`, `i` и `c` идут к новому
стационару после шока — всё в долях от исходного уровня.

**Потребление и норма сбережений.** Горб `c*(s)` с вершиной
в золотом правиле и текущей нормой сбережений на нём.

## Главная идея

Две группы ползунков устроены нарочито по-разному, и в этом весь смысл.

* **Параметры `s`, `δ`, `n`, `g`, `α`, `σ` двигают кривые, но не двигают
  точку `k`.** Экономика может хоть завтра поднять норму сбережений —
  запас капитала от этого не подпрыгнет, он накоплен прошлым.
  Кривые уезжают, точка остаётся, между инвестициями и выбытием
  открывается разрыв. Этот разрыв и есть переходная динамика.

* **Множители шока `K ×` и `L ×` наоборот двигают точку, не трогая
  кривые.** Война, эпидемия, волна миграции меняют `k = K/(L·A)`
  мгновенно, но ни технологию, ни норму сбережений не трогают.

Кнопка «Запустить» проигрывает переход, «Сразу в k\*» переставляет
экономику в стационар, «Запомнить как „было“» оставляет серый пунктир
прежней конфигурации для сравнения.

## Ссылка на конкретную конфигурацию

Все параметры живут в хеше URL, поэтому ссылкой можно задать студентам
ровно ту картинку, которую вы хотите обсудить. Кнопка **«Скопировать
ссылку»** кладёт её в буфер, **«Сохранить PNG»** выгружает диаграмму
на белом фоне и с двойным разрешением — чтобы вставить в презентацию.

## Сценарии

| Сценарий | О чём он |

| Исходное равновесие | точка отсчёта: `s = 0,20`, `δ = 0,10`, `α = 1/3` |
| Задача 1.i — миграция | `L ×1,25`, `K ×0,8`: `k` падает на 36%, а `k*` не двигается |
| Задача 1.ii — δ и s вверх | `δ` 10→12%, `s` 10→20%: `k*` растёт на 115% |

| СССР: низкая эластичность замещения | `σ` 1 → 0,6 при `s = 0,30`: капитал плохо заменяет труд, `k*` уходит вниз — рост обязан был затухнуть ([Easterly & Fischer, 1995](https://www.nber.org/papers/w4735)) |
| Замещение без предела | `σ = 2`, `α = 0,5`, `s = 0,60`: стационара нет вовсе |
| Демографический бум | `n` 0 → 3%: линия выбытия круче, `k*` падает |

## Формулы

Производственная функция — CES, где `σ` управляет тем, насколько легко
капитал замещает труд:

```
f(k) = [α·k^ρ + (1−α)]^(1/ρ),   ρ = (σ−1)/σ
Δk   = s·f(k) − (δ+n+g)·k
```

При `σ = 1` показатель обращается в бесконечность, и функция вырождается
в привычного Кобба — Дугласа `f(k) = k^α`; этот случай считается отдельно.

Стационар — там, где инвестиции ровно покрывают выбытие,
`s·f(k*) = (δ+n+g)·k*`. Средний продукт `f(k)/k` убывает монотонно,
поэтому каждый его уровень `q` достигается не более одного раза:

```
k(q)   = [(1−α)/(q^ρ − α)]^(1/ρ)     — существует, пока q^ρ > α
k*     = k(q) при q = (δ+n+g)/s
k_gold = k(q) при q = ((δ+n+g)/α)^σ
s_gold = α^σ·(δ+n+g)^(1−σ)           — при σ = 1 это знакомое s = α
```

### Когда стационара нет

Условие `q^ρ > α` выполняется не всегда, и это не техническая мелочь,
а содержание модели. `f(k)/k` падает от `A₀` до `A∞`, и границы зависят
от `σ`:

```
σ > 1:  A₀ = ∞,                  A∞ = α^(σ/(σ−1)) > 0
σ < 1:  A₀ = α^(σ/(σ−1)) < ∞,    A∞ = 0
```

При `σ > 1` капитал слишком легко замещает труд: его средний продукт
не падает ниже `A∞`, и если `s·A∞ > δ+n+g`, линия `s·f(k)` уже нигде
не пересечёт линию выбытия — капитал и выпуск растут без предела, модель
вырождается в AK. Инструмент в этом случае не рисует `k*`, а выводит
на диаграмме надпись «стационара нет: капитал растёт бесконечно».

При `σ < 1` бывает зеркальная беда: отдача капитала ограничена сверху,
и при слишком малой `s` инвестиции нигде не покрывают выбытие.

### Отдача капитала и сходимость

```
r  = α·(f(k)/k)^(1/σ) − δ
θ  = α·(k/f(k))^ρ                    — доля капитала в доходе
λ  = (1 − θ*)·(δ+n+g)
```

Под CES доля капитала `θ` не равна `α`: `α` становится параметром
распределения, а не долей. При `σ = 1` всё это сворачивается обратно
в `r = α·k^(α−1) − δ` и `λ = (1−α)(δ+n+g)` — отсюда и знаменитые
«2% в год»: при `α = 1/3` и `δ+n+g ≈ 0,06` получается `λ ≈ 0,04`,
а разрыв с наблюдаемой скоростью сходимости — повод поговорить
о человеческом капитале.

### Зачем здесь σ

Easterly и Fischer в «The Soviet Economic Decline» ([NBER WP 4735](https://www.nber.org/papers/w4735),
1995) показывают, что советское замедление хорошо описывается низкой
эластичностью замещения между капиталом и трудом. При `σ < 1` высокая
норма сбережений упирается в быстро падающую отдачу капитала: страна
может годами вкладывать треть выпуска и всё равно выйти на скромный
стационар. Сценарий «СССР» в инструменте показывает ровно это —
`σ` падает с 1 до 0,6, запас капитала остаётся на месте, а `k*` уходит
вниз, и экономике остаётся только сползать к нему.

## Локальный запуск

```bash
git clone https://github.com/Nerbi357/solow-model.git
cd solow-model
python3 -m http.server 8000
```

Дальше `http://localhost:8000/`. Можно и просто открыть `index.html`
в браузере — страница не делает сетевых запросов и работает из файла.
