# Модель Солоу — интерактивная диаграмма

Учебный инструмент для семинара по макроэкономике. Одна страница, на
которой видно то, ради чего диаграмма Солоу вообще рисуется: кривые
уезжают сразу, а накопленный капитал — нет, и между ними открывается разрыв,
который экономика закрывает годами.

**Живая страница: https://nerbi357.github.io/solow-model/**

Весь инструмент — один файл `index.html` без внешних зависимостей.
Его можно скачать и открыть двойным щелчком: интернет нужен только
чтобы получить файл, дальше он работает офлайн — с флешки, в аудитории
без вайфая, с телефона в самолёте.

## Главная идея

Две группы ползунков устроены нарочито по-разному, и в этом весь смысл.

* **Параметры `s`, `δ`, `n`, `g`, `α` двигают кривые, но не двигают
  точку `k`.** Страна может хоть завтра поднять норму сбережений —
  запас капитала от этого не подпрыгнет, он накоплен прошлым. Кривые
  уезжают, точка остаётся, между инвестициями и выбытием открывается
  разрыв. Этот разрыв и есть переходная динамика.

* **Множители `K ×` и `L ×` наоборот двигают точку, не трогая кривые.**
  Война, эпидемия, волна миграции меняют `k = K/L` мгновенно, но ни
  технологию, ни норму сбережений не трогают.

Ровно из этого различия и растёт вся таблица: краткосрочно работает
только то, что изменилось мгновенно, долгосрочно — то, куда экономика
в итоге придёт.

## Что внутри

**Исходное состояние и до трёх шоков.** Шоки **одновременны** и все
отсчитываются от исходного состояния, а не друг от друга: в задачах
написано «δ выросла, а s увеличилась», а не «сначала одно, потом
другое». Один шок меняет ровно один параметр — занятый параметр
исчезает из списка добавления.

**Три формы шока**, потому что в листках встречаются все три:

| Форма | Как читается | Пример |
|---|---|---|
| `→ новое` | названы оба конца | `s: 0,10 → 0,20` |
| `+ на сколько` | приращение в пунктах | `δ + 5 п.п.` |
| `× во сколько` | множитель | `K ×0,80`, `L ×1,25` |

**Цвет говорит только о шоках.** Исходное состояние — все три кривые
чёрные, обычной толщиной, сплошной линией; какая это кривая, видно по
подписи у правого края. Шок перекрашивает жирным **только ту линию, на
которую он влияет**: `s` — инвестиции, `δ`/`n`/`g` — линию выбытия,
`α` — обе кривые выпуска, `K ×` и `L ×` — ни одной, они двигают точку.
Шок, стоящий на нейтральном значении, не красит ничего.

**Таблица «Что происходит с переменными».** Строка на каждый шок — его
изолированный эффект, плюс «итого» со всеми сразу. Ответов ровно
четыре, как на семинарском листке: увеличилось, уменьшилось,
не изменилось, нельзя определить.

**«Задано» и «свободно» — сердце правильности.** У каждого параметра
исходного состояния два независимых свойства: значение и статус.
**По умолчанию свободны все пять**: пока условие не назвало число,
инструмент не считает его известным. Нужны свои данные — нажмите
«свободно» у нужного параметра, и ползунок отпустит.
Значением рисуется картинка, статусом считается таблица. «Задано» —
условие назвало это число. «Свободно» — условие молчит, и тогда
инструмент **перебирает весь допустимый диапазон**: если знак где-то
переворачивается, ответом становится «нельзя определить». Порога вида
«растёт при α > 0,145» под таблицей нет намеренно: при нескольких
свободных параметрах он верен ровно для одной случайной калибровки,
а выглядит как ответ.

Это не украшение, а способ не соврать. Семинарский листок спрашивает
«что произойдёт?», а не «что произойдёт при α = 1/3». Свободный
параметр двигает картинку, но ответа в таблице не меняет — и это
хорошо видно студентам: график едет, а в клетке по-прежнему «?».

**Развилка: две диаграммы там, где одна соврала бы.** Шок по `α`
разворачивает кривую выпуска вокруг `k = 1`: правее рост `α` выпуск
поднимает, левее — опускает. Если свободные параметры допускают обе
стороны, одна картинка показала бы один случай из двух и при этом
выглядела бы ответом. Инструмент рисует обе — `k < 1` и `k > 1`, одна
под другой, и ни одна не главная. Развилка в модели ровно одна, у `α`:
все прочие параметры двигают кривые в одну сторону независимо от того,
где стоит экономика.

**Траектории во времени.** Под таблицей четыре маленьких графика: что
делает каждая величина от шока до нового стационара. Большая диаграмма
показывает «откуда куда», эти — «как»: скачок в момент шока и медленное
сползание после него. Где направление не определено, вместо кривой
стоит вопрос — уверенная линия соврала бы так же, как одна диаграмма
на развилке.

**Координаты точек.** Щелчок по кружку на пересечении разворачивает
координаты; второй кружок показывает разницу `Δk` и `Δy` к первому.
Картинка безразмерная, поэтому всё считается в долях от исходного
стационара: он равен `(1; 1)`.

**Ещё по мелочи.** Golden rule по кнопке, масштаб колесом и
перетаскиванием, ссылка на конкретную конфигурацию, выгрузка PNG
на белом фоне и с двойным разрешением (на развилке — обе диаграммы),
пять разобранных задач
с семинара.

## Ссылка на конкретную конфигурацию

Всё состояние живёт в хеше URL — исходные значения со статусами, шоки
с формами, открытая задача и отмеченные точки. Ссылкой можно задать
студентам ровно ту картинку, которую вы хотите обсудить. Кнопка
**«Скопировать ссылку»** кладёт её в буфер.

## Модель

Производственная функция — Кобб — Дуглас. CES и эластичность замещения
из инструмента убраны намеренно: все задачи семинара — Кобб — Дуглас,
в листках это написано прямым текстом.

```
f(k) = k^α
Δk   = s·f(k) − (δ+n+g)·k
k*   = (s/(δ+n+g))^(1/(1−α))
s*   = α                       — золотое правило при Коббе — Дугласе
λ    = (1−α)(δ+n+g)            — скорость сходимости
```

Полезно помнить одну вещь, на которой держатся половина задач: функции
`k^α₀` и `k^α₁` пересекаются ровно в `k = 1`. Поэтому как только шок
меняет `α`, знак почти всего упирается в то, больше или меньше единицы
исходная капиталовооружённость — а это `(s/δ)^(1/(1−α))`. Если `s` или `δ` не заданы,
ответ честно не определён.

Всё считается в логарифмах: при `α` близких к единице показатель
`1/(1−α)` огромен, и обычная арифметика переполняется молча.

## Разобранные задачи

| Задача | О чём она |
|---|---|
| 1. K вниз, L вверх | `K ×0,80`, `L ×1,25`: `k` падает на 36%, а стационар стоит — долгосрочно не меняется ничего |
| 2. s вверх, δ вверх | `s` 10→20%, `δ` 10→12%: стационар уезжает вправо, а потребление упирается в неназванную `α` |
| 3. K вверх, g вверх | `K ×1,10`, `g + 5 п.п.`: краткосрочно всё вверх, долгосрочно всё вниз, и ответ не зависит ни от одного неизвестного |
| 4. s вверх, α вверх | `s` 20→22%, `α` 30→35%: сторону решает неназванная `δ`, поэтому диаграмм две и почти всё не определено |
| 5. n вверх, α вверх | `n` 0→2%, `α` 40→45%: капиталовооружённость падает при любой `s`, остальное упирается в неё же |

### Как добавить свою

Разборы лежат в массиве `PROBLEMS` в `index.html`, формат описан
комментарием прямо над ним:

```js
{
  title: "Задача 1. K вниз, L вверх",
  ask  : "Модель Солоу с производственной функцией Кобба — Дугласа…",
  // шаг разбора — тройка: заголовок, рассуждение, ответ этого шага.
  // Рассуждение — строка или массив абзацев; выкладка отдельной строкой
  // пишется как '<code class="calc">s·f(k₀) = (δ+n+g)·k₀</code>'
  why  : [["Какие кривые двигаются?", ["Никакие…", "…"], "Кривые стоят, двигается точка."],
          ["Что происходит в краткосрочном периоде?", "…", "Падают все четыре величины."],
          ["Что происходит в долгосрочном периоде?", "…", "Не меняется ничего."]],
  // [значение, задано]: 1 — условие называет это число, 0 — молчит
  base : {s:[.20,0], d:[.10,0], n:[0,1], g:[0,1], a:[1/3,0]},
  shocks: [{key:"K", form:"mul", value:.8}, {key:"L", form:"mul", value:1.25}]
}
```

Заголовки шагов во всех задачах одни и те же: это метод, а не изложение —
студент уносит с семинара процедуру, которая работает на любой задаче.
Ответ стоит под своим шагом, а не один общий в конце.

Вторая цифра в `base` — самое важное место. Именно она решает, что
инструмент будет перебирать, а значит, где в таблице появится «нельзя
определить». Ставьте `1` только там, где условие действительно называет
число.

Больше нигде править ничего не нужно: список, кнопки и таблица
соберутся сами.

## Проверка

```bash
bash check/all.sh            # всё сразу: ~10 минут, сервер поднимается сам
```

Или по частям:

```bash
python3 check/seminar.py     # независимый пересчёт всех пяти таблиц
python3 -m http.server 8000  # нужен для всего, что ниже
node check/audit.js          # ~3000 конфигураций против своей модели
node check/ui-core.js        # браузерные наборы, их шесть
```

Оба скрипта написаны слепо: модель в них выписана заново и ни строчки
из `index.html` не берёт. Если скрипт и страница разошлись — кто-то
из них врёт, и надо разбираться, а не подгонять.

`check/audit.js` открывает страницу в headless-браузере (нужен
`playwright-core` или `playwright`) и сверяет её таблицы со своими
клетка за клеткой, а сверх того держит инварианты вроде «нет шока по
запасу — значит `k` краткосрочно не менялся» и «всё задано — значит
«?» в таблице невозможен».

`check/ui-*.js` — девять браузерных наборов, 254 проверки: поведение
ползунков и форм шока, подписи на диаграмме, кнопка «Показать ответ»,
траектории, вёрстка на ширинах от 1600 до 390 пикселей, развилка
по α — стороны, читаемость картинки и независимый зум у двух диаграмм.

## Локальный запуск

```bash
git clone https://github.com/Nerbi357/solow-model.git
cd solow-model
python3 -m http.server 8000
```

Дальше `http://localhost:8000/`. Можно и просто открыть `index.html`
в браузере — страница не делает сетевых запросов и работает из файла.
